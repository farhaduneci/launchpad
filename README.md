# Launchpad

A minimalist text-based Android home screen replacement.

- **App Slots**: Assign apps to 10 fixed tap positions
- **App List**: Full alphabetical list on swipe-up, text only
- **Chest**: Secondary space for rarely-used apps — hidden but directly launchable
- **Renaming**: Custom display names for any app
- **Customize**: Font, scale, colors, drawer alignment, transparent background

## Development

- Kotlin / Jetpack Compose
- Android 9.0+ (minSdk 28)
- No Google APIs, no tracking, no internet permission

```bash
./gradlew assembleDebug
./gradlew :app:testDebugUnitTest
```
